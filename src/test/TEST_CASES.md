## 2. Service Layer Unit Tests

Service unit tests isolate pure business logic using Mockito without spinning up Spring's ApplicationContext.

### `AuthServiceTest`
- **File**: `src/test/java/com/litmus/authPortal/service/AuthServiceTest.java`
- **Annotations**: `@ExtendWith(MockitoExtension.class)`

| # | Test Case Method | Description | Input / Arrange | Expected Result |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `registerUser_ShouldHashPasswordAndSaveUser` | Password encoding and persistence of a new local user. | Plain password `"plainPassword"`. | Returns saved user with hashed password and `AuthProviderIdentity.LOCAL`. |
| 2 | `userExists_WhenUserFound_ShouldReturnTrue` | Checks existence when username exists. | Mock `usersRepo.findByUsername` returns a user. | Returns `true`. |
| 3 | `userExists_WhenUserNotFound_ShouldReturnFalse` | Checks existence when username does not exist. | Mock `usersRepo.findByUsername` returns `null`. | Returns `false`. |
| 4 | `loginUser_WithValidCredentials_ShouldReturnJwtToken` | Generates token upon valid login credentials. | Mock `authManager.authenticate` returns authenticated token. | Returns generated JWT token string. |
| 5 | `loginUser_WhenNotAuthenticated_ShouldThrowBadCredentialsException` | Throws exception when authentication fails. | Mock `authManager.authenticate` returns unauthenticated token. | Throws `BadCredentialsException`. |
| 6 | `generateOtpForEmail_Unauthenticated_WhenUserExists_ShouldSendOtp` | Sends OTP to existing user when unauthenticated. | Unauthenticated context; user exists in DB. | Calls `otpService.generateOtp` and `emailService.sendOtpMail`. |
| 7 | `generateOtpForEmail_Unauthenticated_WhenUserDoesNotExist_ShouldNotSendOtp` | Aborts OTP generation for non-existent email. | Unauthenticated context; user does not exist. | Never calls `otpService` or `emailService`. |

## 5. End-to-End Integration Tests

Integration tests load the full Spring context and verify complete user journeys from HTTP request to database and back.

### `AuthPortalIntegrationTest`
- **File**: `src/test/java/com/litmus/authPortal/integration/AuthPortalIntegrationTest.java`
- **Annotations**: `@SpringBootTest`, `@AutoConfigureMockMvc`, `@Transactional`

| # | Test Case Method | Description | Steps Tested |
| :--- | :--- | :--- | :--- |
| 1 | `fullAuthLifecycle_ShouldSucceed` | End-to-End User Authentication & Email Verification Journey | 1. **Register**: `POST /register` creates new user in DB.<br>2. **Login**: `POST /login` authenticates user & issues JWT.<br>3. **Request OTP**: `POST /auth/email-otp/send` generates OTP in database.<br>4. **Verify Email**: `POST /auth/verifyEmail` marks user as email-verified.<br>5. **Protected Access**: `GET /hello` with Bearer token returns `200 OK`.<br>6. **Unauthorized Access**: `GET /hello` without token returns `401 Unauthorized`. |

## Running the Tests

To execute all 46 test cases:
```bash
./mvnw clean test
```

To run a specific test class:
```bash
./mvnw test -Dtest=UsersRepositoryTest
./mvnw test -Dtest=AuthServiceTest
./mvnw test -Dtest=JwtFilterTest
./mvnw test -Dtest=ControllerTest
./mvnw test -Dtest=AuthPortalIntegrationTest
```
